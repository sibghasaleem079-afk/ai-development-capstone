About

Where I'm coming from

I'm a junior developer who builds software around problems I actually notice. I started with Pet Care Guide, a Java application inspired by problems I had with my own cat. My current project, StudentStay, is based on an accommodation problem I noticed among students moving to Sahiwal for university.

I use AI as a coding and debugging assistant, but the ideas, features, and decisions behind my projects are mine. I'm still learning, and each project is helping me build better.

I started with Java and object-oriented programming, then moved into web development with React and JavaScript. My projects usually start with a problem I notice rather than a technology I want to use.

I'm still learning, so I don't want to present myself as someone who already knows everything. I want my portfolio to show what I can build now, how I approach problems, and how I'm improving from one project to the next.

Proof Statement

I can turn real-world problems into useful software solutions. I observe problems around me and try to build practical, user-friendly solutions for them. Pet Care Guide and StudentStay show how I take a problem, think about what would actually help, and turn that idea into software.

I'm looking for a junior development opportunity where I can work on real projects, keep learning, and continue improving as a developer.
