# Project Guidelines

## Stack
- Language: JavaScript
- Framework: React
- Build Tool: Vite
- Styling: CSS
- Routing: React Router DOM

## Project Structure
- `src/components/` for reusable UI components
- `src/pages/` for page-level components
- `src/assets/` for images and other assets
- Keep components small and reusable

## Coding Conventions
- Use functional React components
- Use clear and meaningful variable names
- Use camelCase for variables and functions
- Use PascalCase for React component names
- Keep CSS in separate files where practical
- Avoid unnecessary duplicate code
- Keep the code simple and readable

## Git Conventions
- Use Conventional Commits
- Examples:
  - `feat: add search functionality`
  - `fix: resolve routing issue`
  - `docs: improve README`

## General Rules
- Do not change unrelated files
- Test changes before considering a task complete
- Prefer simple solutions over unnecessary complexity
